# 보유 시험지 전체 객관식 평가

## 범위

최상위 폴더의 시험지 PDF 11개를 조사한다. 세무사 2차 세법학1부·세법학2부·회계학1부·회계학2부 4개는 서술형이므로 제외한다. 나머지 객관식 포함 파일 7개를 모두 평가한다.

| 파일/유형 | 평가 문항 노출 수 |
|---|---:|
| 세무사 1차 1교시 | 80 |
| 세무사 1차 2교시 민법 선택 | 80 |
| 세무사 1차 2교시 상법 선택 | 80 |
| 세무사 1차 2교시 행정소송법 선택 | 80 |
| 수능 국어: 홀수·짝수, 공통·화법과 작문·언어와 매체 | 112 |
| 수능 수학: 홀수·짝수, 공통·확률과 통계·미적분·기하의 객관식 | 66 |
| 수능 영어: 홀수·짝수 독해 18~45 | 56 |
| 합계 | 554 |

수학 공통 16~22와 각 선택과목 29~30은 단답형이므로 제외한다. 영어 듣기 1~17은 제외한다. 음원이나 대본으로 대체해 합산하지 않는다.

**554개는 독립적인 고유 문항 수가 아닌 파일·형별 노출 수다.** 세무사 2교시 3개 파일에는 같은 회계학개론 40문항이 반복된다. 수능 홀수·짝수형도 상당 부분 같은 내용이다. 이들을 독립 표본 554개로 간주한 유의성 검정이나 일반화 주장을 하지 않는다.

## 입력과 공정 비교

수학 수식·분수·지수·그림은 원본 PDF의 **150dpi 페이지 이미지**로 전달한다. PDF에서 추출한 깨진 문자나 PUA 코드를 수식 대신 모델에 보내지 않는다. 모든 과목이 이미지 입력이며 정답표는 모델에 전달하지 않는다.

국어의 공통 지문은 문항 묶음별 실제 지문 페이지를 추가 제공한다. 예를 들어 4~9번은 2~3쪽, 27~30번은 9~11쪽을 함께 보낸다. 선택과목은 해당 선택과목의 4쪽을 함께 보낸다. 원본과 처리본에 동일한 페이지 묶음·같은 문항 목록을 사용한다. 세무사·수학·영어의 선택된 자기완결적 문항은 해당 페이지로 평가한다.

Qwen2.5-VL 3B Q4_K_M, 동일 모델 digest, temperature 0, seed 42, 문맥 16384, 출력 1024, 선택지 정수 1~5 JSON schema를 사용한다. 원본과 `source` 글자 재사용 모드의 2단계를 비교한다. 과거 실행에는 3단계(구분선 무늬)도 있었으나 추가 효과가 없어 2026-11-17에 기능과 함께 삭제했다. 워터마크 조건은 글자 6pt, 농도 0.45, 크기 변동 ±25%, 테두리 20pt, QR 36pt다. QR 크기는 CLI 기본값이며 웹 화면의 초기값 40pt와는 다르다. 이전 한 시험지 실험과 입력 컨텍스트·출력 상한 등이 다르므로 이전 점수와 직접 묶어 분석하지 않는다.

점수표의 `accuracy`는 **선택된 객관식 문항의 정답률**이다. 수능 전체 원점수, 선택과목 조정점수, 표준점수, 등급이 아니다. 국어·수학의 공식 배점도 별도 보존하지만, 여러 선택과목·형을 한 파일에 합친 값이므로 파일 합계를 공식 수능 100점 만점 점수라고 부르지 않는다.

## 실행·보존·공개

수학 시험의 테두리를 수식 문구로 바꾸던 v6 보강 스크립트(`enhance_corpus.py`)와 수식 워터마크는 2026-11-17에 삭제했다. 그 실행의 결과 문서와 JSON은 기록으로 남아 있지만 현재 코드로는 재현할 수 없다.

### 실행

```powershell
.venv/Scripts/python.exe evaluation/corpus_evaluation.py --prepare
.venv/Scripts/python.exe evaluation/corpus_evaluation.py
```

기존 생성물을 준비하는 프로세스와 추론을 겹쳐 실행할 때는 추론 측에 `--pipeline`을 사용한다. 생성 PDF는 `outputs/corpus_evaluation_v4`, 최종 평가 응답·설정·정답표·집계는 `outputs/corpus_evaluation_v5`에 보존한다. v3/v4의 중단된 예비 응답을 v5 결과에 섞지 않는다. 중단 시 기존 응답 파일을 그대로 읽어 이어서 진행한다.

공개 저장소에는 코드와 식별 가능한 문항 번호·정오·숫자 점수 및 보고서를 올린다. 원본 시험지, 원문 문제·지문, 생성 PDF, 모델 가중치, IP·사건 기록, 임시 다운로드는 올리지 않는다.

한 개 소형 모델의 결과이므로 원본 점수가 우연 수준 부근일 경우 바닥 효과를 고려해야 한다. JSON schema를 쓰므로 자유 응답 언어 변경 유도 성능을 직접 측정하지 않는다. 더 낮은 점수를 얻도록 사후에 정답표·입력·채점 방식을 바꾸지 않는다.

조건 순서는 원본→2단계로 고정돼 있고, 반복 실험·순서 무작위화·워밍업 통제는 하지 않았다. 그러므로 지연 시간의 우열이나 작은 정답률 차이의 원인을 단정하지 않는다. 파일별 원본 정답 수를 함께 공개해 모델의 기본 풀이 능력과 처리 효과를 구분한다.
