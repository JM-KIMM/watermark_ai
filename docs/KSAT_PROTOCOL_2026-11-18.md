# 공개 수능 벤치마크의 원본/워터마크 짝지은 비교

2026-11-18, 추론 전에 고정한다. [roboco-io/KSAT-AI-Benchmark](https://github.com/roboco-io/KSAT-AI-Benchmark)의 2026학년도 홀수형 PDF·문항 메타데이터를 사용한다. upstream commit, 파일 hash, 출처 manifest를 보관한다. 원 저장소의 코드를 실행·복제하거나 리더보드에 제출하는 것이 아니라, 같은 문항을 우리 로컬 모델로 짝지어 평가하는 독립 실험이다. upstream의 CC BY-NC 4.0 표기를 존중하며 시험지·upstream 자료는 비공개 outputs에서만 사용한다.

KoNET/KoCSAT도 조사했지만 이번에는 과목별 공식 배점과 원본 PDF가 함께 있는 KSAT 자료를 선택했다. 다른 벤치마크를 기억한 사용자 답변이 오면 별도로 구분한다. 기존의 로컬 LLM 사용 선호에 따라 Qwen2.5-VL 7B와 Tesseract→Qwen2.5 7B를 사용한다. 공개 리더보드의 상용 모델 점수와 직접 우열 비교하지 않는다.

## 표본·정답·점수

전체147개 고유 문항 중 영어 듣기1–17과 수학 단답형13개를 제외한 객관식117개 전부: 국어56(공통34+화작11+언매11), 수학33(공통15+선택6씩3개), 영어28. 공통 문항을 전체 집계에서 중복하지 않는다. 국어는 선택과목별45문항100점, 수학·영어는 평가에 남은 문항의 배점 합계를 분모로 보고한다. 수학 단답형을 틀린 문제로 넣거나 전체100점으로 환산하지 않는다.

정답과 배점을 upstream JSON과 별도로 PDF 정답표의 번호/원문 원형숫자/배점에서 추출해 검증한다. 영어37은 공식 정답⑤를 주 분석으로 사용한다. upstream이 별도로 인정한④/⑤ 정책은 민감도 결과로만 공개한다. 정답·배점은 모델 요청에 넣지 않는다. 반복 번호는 과목·선택과목을 포함한 고유 ID로 구분한다.

## 조건

- original: 홀수형 원본 페이지.
- control: QR 행 예약과20pt 바깥 띠만 있는 동일 기본 배치.
- product: 현재 `webapp.build_options({})` 기본값 그대로 생성한 PDF(2단계, 문항 끝 QR, 지문 프레임·테두리 문구). 추적 서버는 사용하지 않으며 모델에는 도구가 없다.
- notice: control에 이전 실험의 답안 중단 안내만 추가한 실험용 후보. product와 다른 조건이며 이를 현재 제품의 결과로 바꿔 부르지 않는다.

원본 수식·도형을200dpi 이미지로 렌더링한다. OCR 경로는 같은 렌더링에 Tesseract kor+eng PSM3을 사용하므로 수학 인식 한계를 따로 밝힌다. 추가 표시 영역 밖의 control/product 및 control/notice 픽셀 차이를 검사한다. 선언한 프레임 영역 내부의 사람 가독성은 이 검사로 증명하지 않는다.

로컬 문맥 길이 때문에 upstream의 과목 전체 요청 대신 페이지별 문항 묶음을 사용한다. 국어는 같은 선택과목 구간 안의 이전·현재·다음 페이지를 함께 주어 지문 문맥을 보존한다. 수학은 해당 페이지, 영어는 이전·현재·다음 페이지(듣기 전용1쪽 제외)를 사용한다. 요청에 지정한 객관식 번호만 채점한다. 이 변경 때문에 upstream 리더보드의 공식 재현 점수라고 주장하지 않는다.

## 추론·분석

두 경로×네 조건×117문항=936개 문항 응답. 같은 시스템·사용자 지시, 짧은 풀이 후 최종 번호 JSON. 번호 정수/null 허용(1–5 enum 강제 없음), 온도0, seed2026111804, 문맥32768, 출력2048. API/형식 오류는 최대3회 재시도 후 별도 실패로 기록한다. null과 범위 밖 번호는 비정답이나 실패와 구분한다. 문제에 대한 외부 검색·도구·정답 접근은 없다.

정답 수·배점 점수·미응답·잘못된 번호·실행 실패를 과목 및 선택과목별로 공개한다. original→product가 사용자 관점의 총변화, control→product가 배치 효과를 줄인 주 비교다. 실제 입력 문맥을 공유하는 묶음으로 bootstrap/sign-flip하고 두 경로 주 비교에 Holm 보정한다. notice는 별도 탐색 조건이며 가장 낮은 점수만 골라 제품 효과로 주장하지 않는다. 기존 시험지로 문구를 개발했지만 이117문항으로 문구를 재튜닝하지 않는다. 여러 seed·상용 모델·물리 촬영·사람 실험은 포함하지 않는다.
