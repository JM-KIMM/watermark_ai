# 실제 시험지 전이 검사

2026-11-18, 합성 후보 선택/검증 결과가 나오기 전에 고정한다. 개발 집합에서 선택한 후보 하나를 이전에 수집한 영어 3회분 84문항에 전이한다. 이 코퍼스는 이미 결과를 본 자료이므로 새로운 독립 holdout이 아니며 탐색적 전이 검사다. 합성 검증이 실패해도 결과를 숨기지 않고 전이 결과와 나란히 보고한다.

입력은 기존 layout control PDF에 같은 후보 문구만 사방 중 위·아래 20pt 띠에 넣은 것이다. 원래 본문·QR용 빈 행·크기·수식은 그대로 유지한다. 기존 프레임/QR 전체 구성이 아니라 새로운 문구만의 배치 실험이다. 5.5pt 두 줄로 인쇄하고 픽셀 차이가 띠 밖에서 0인지 검사한다. 유효 번호 후보면 페이지의 각 문항에 정답과 독립적인 hash 번호를 표시하고, 순환 후보면 동일 표를 쓴다. 본문/정답표를 읽어 문구를 최적화하지 않는다.

대조군, 후보, 후보+무시 지시를 두 로컬 경로에서 모두 새로 실행한다: 21요청×3조건×2경로=126응답 묶음, 504문항 응답. 모델·프롬프트·JSON 구조·문맥·seed는 기존 v2와 동일하며 번호 enum은 사용하지 않는다. 오류/미응답/번호6을 구분한다. 정상 풀이 후 최종 답만 채점한다.

대조군→후보의 주 비교 두 개에 cluster bootstrap·sign-flip permutation 및 Holm 보정을 적용한다. 무시 지시 비교는 보조 분석이다. 후보가 유효번호를 우연히 정답으로 제시한 경우도 주 분석에서 제외하지 않는다. 별도 지표로 표적 일치와 정답 손실/회복을 공개한다. 한 경로의 성공을 다른 경로·실물사진·AI안경에 일반화하지 않는다.
