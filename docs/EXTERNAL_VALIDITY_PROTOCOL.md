# 추가 시험지와 측정 타당성: 실행 전 계획

2026-11-17. 기존 결과를 본 이후 설계한 외부 코퍼스 반복 연구다. 공개 등록기관의 preregistration은 아니며 실행 전 파일 해시를 고정한다. 유리한 효과를 얻기 위한 재선정은 하지 않는다.

## 연구 질문과 모집단

2023년 9월·2024년 9월·2025년 6월 고3 모의평가 영어를 추가 수집한다. 전부 18~45번 독해 객관식 28문항, 합계 84문항. 듣기 1~17은 제외한다. KICE 제작 원문을 공개 미러에서 확보하고 EBS 해설의 정답표와 대조한다. 공식 CDN 접근 실패도 기록한다. 세 시험은 영어에 한정되므로 과목 전체의 외적 타당성이 확보됐다고 하지 않는다. 모델 학습 데이터와 겹치지 않는다는 보장도 없다.

## 설계

- Qwen2.5 7B + Tesseract kor+eng와 Qwen2.5-VL 7B를 사용한다. 실제 생성기 `frames / labelled / absent(6번)`를 적용한 PDF의 200dpi 렌더를 사용한다.
- A 원본, B 동일한 페이지 배치에서 방해 문구 영역을 제거한 대조군, C 현재 생성기 출력, D C + 시스템 수준 무시 지시를 비교한다. B는 C에서 명시된 장식 영역만 원본/백색으로 대체하며 문제 본문 차이를 검사한다. 불가능하면 이유를 공개하고 B를 다른 인과 대조군으로 바꾸지 않는다.
- 단순 첫 토큰 확률만으로 최종 답을 주장하지 않는다. 한 페이지의 문항을 묶어 짧은 근거와 최종 번호를 JSON으로 생성한다. 1~5 번호만 허용하는 grammar는 사용하지 않는다(6번 출력도 관측 대상). JSON 구문만 요청하고 형식 실패를 따로 기록한다. 41~42, 43~45 지문을 함께 포함한다.
- 주 비교는 B 대 C의 최종 정답률이다. 보조 비교는 A 대 C, C 대 D. 문항/요청 단위의 교차 의존성을 기록한다. 원본에서 맞힌 문항만 사후 골라 주 분석하지 않는다.
- 입력 해시·모델 digest·프롬프트·토큰 사용량·전체 응답·정답 출처를 로컬 저장한다. 공개 결과에는 시험 원문과 응답에 복제된 긴 지문을 포함하지 않는다.

## 분석

1. 정답률·오답·6번 선택·미응답·형식 실패·문항별 전이와 시험별 이질성.
2. 짝지은 McNemar exact 검정(문항 독립 가정의 한계를 명시), 요청/공통지문 묶음 bootstrap 95% CI, cluster sign-flip permutation 검정. 주 비교 두 경로에 Holm 보정.
3. 기존 확률 자료의 정답 확률 변화·JSD·엔트로피·Brier score·log loss·5개 동일 폭 bin ECE. top-20 미반환 질량과 조건부 정규화 구분. 잘린 분포의 추정값은 민감도 분석으로 공개.
4. 기존 합성 입력의 OCR 문자 오류와 정답 번호/실제 계산값 혼동, 첫 토큰 대 완성 답안 불일치 검증. 프롬프트 명확화와 보기 순환 순서 변경 검사를 별도의 진단 실험으로 수행한다.
5. 기존 영역 제거 히트맵은 단일 문항의 output sensitivity로만 해석한다. 내부 가중치 접근이 없는 모델에서 parameter randomization sanity check나 Grad-CAM을 했다고 쓰지 않는다. 빈 영역 제거 음성 대조군과 본문 제거 양성 대조군을 비교한다.

## 중단·누락·검증

성능이 나쁘거나 예상과 반대라는 이유로 중단하지 않는다. 소스 파싱/정답 매핑/필수 입력 검증 실패는 결과를 보기 전에 고쳐 기록한다. 응답 실패는 2회까지 재시도하고 실패율·분모를 공개한다. 통계적 유의성은 실제 효과 크기와 구분한다. 사람 가독성/현장 부정행위 감소/상용 모델은 이 실험으로 입증하지 않는다.

## 실행 중 수정: v2

첫 실행의 영상 경로에서 `question` 예시 키 복사, 중복 JSON 키, 지문 장문 전사와 출력 초과가 반복됐다. 형식 오류를 관측한 뒤 v1을 중단하고 원시 응답·설정·코드를 보존했다. 이 수정은 완전히 결과를 보기 전의 사전 고정이 아니므로 탐색적 프로토콜 수정으로 공개한다. 두 경로 모두 모든 조건을 새로 실행한다.

v2는 문항 번호 키와 reasons/answers 구조를 JSON schema로 고정한다. answers는 제한 없는 integer 또는 null이며 1~5 enum을 사용하지 않으므로 6번도 허용된다. 근거는 15단어 이내로 요청한다. 그림·OCR·정답표·조건은 바꾸지 않는다. 이는 형식 측정의 개선이며 v1의 높은 실패율을 방해 효과로 해석하지 않는다. 본 연구의 주 결과는 responses_v2이고 v1은 형식 실패 감사에만 사용한다.
