# 정답 개수와 과목별 배점의 구분

현재 엄격 평가의 주 지표는 554문항 노출의 정답 개수·정답률입니다. 고정된 목록의 영어·세무사 `weights=1`은 문항 개수 단위입니다. 이 값을 실제 시험의 배점 점수로 부르면 부정확합니다. 과거 정답 개수 86·100·97은 이 배점 문제로 바뀌지 않습니다.

이 구분은 2026-11-17 실행 도중, 영어 문항의 새 모델 응답을 수집하기 전에 점검했습니다. 이미 고정한 추론 조건·원본·정답·선정 표본·주 지표는 수정하지 않습니다. 보충 과목 점수는 별도 코드 `evaluation/strict_score_units.py`로 산출하고, 기존 동결 집계와 구분합니다. 코드와 이 설명을 결과 공개보다 먼저 기록합니다.

- 영어: 원본 시험지의 `[3점]` 표시를 공간상 해당 문항과 대조했습니다. 읽기 18~45번 중 24·30·32·34·37·39·41번은 3점, 나머지는 2점으로 읽기 영역 만점은 63점입니다. 듣기는 점수에도 포함하지 않습니다. 홀수·짝수 모두 같은 배점입니다.
- 국어: 공식 정답표에서 추출한 2·3점 배점을 유지합니다. 공통과목과 선택과목 **하나**를 합친 100점 단위로 보고합니다. 화법과 작문과 언어와 매체를 한 응시자 점수에 동시에 더하지 않습니다.
- 수학: 공식 정답표의 2·3·4점 배점을 유지합니다. 공통 객관식과 선택과목 하나를 합친 68점 단위로 보고합니다. 제외한 단답형의 점수를 0점으로 더해 100점 만점 성적인 것처럼 제시하지 않습니다.
- 세무사: 1~40번과 41~80번을 각각 분리하고, 40개 동일 가중 문항을 100점으로 환산합니다. 이 표는 문항당 2.5점의 **환산 점수**로 명시합니다. 과목당 100점 기준은 [국세청 2026년 안내](https://b.nts.go.kr/changwon/na/ntt/selectNttInfo.do?mi=6144&nttSn=1348180)를 참고했습니다.

여러 선택과목·홀짝형·공통 회계의 결과를 서로 독립인 수험생 점수로 평균 내지 않습니다. 출력·통신 오류는 미해결 개수도 함께 표시하고 확정 오답으로 조용히 대체하지 않습니다. 과목 점수 표에서 미해결 문항이 있으면 모두 틀렸거나 모두 맞았을 때의 점수 범위를 표시합니다.

영어는 [평가원 형식의 정답·배점표 사본](https://mathpowergen.com/wp-content/uploads/2025/11/2026%ED%95%99%EB%85%84%EB%8F%84-%EB%8C%80%ED%95%99%EC%88%98%ED%95%99%EB%8A%A5%EB%A0%A5%EC%8B%9C%ED%97%98-%EC%98%81%EC%96%B4-%EC%A0%95%EB%8B%B5.pdf)을 별도로 내려받아 홀수·짝수 읽기 56개 정답이 고정 목록과 일치하는지도 확인했습니다. 이 파일은 제3자 사이트의 사본이며 평가원 직접 다운로드 링크는 확인 당시 404였습니다. 파일 SHA-256은 `363ce5277acb4fda6a6499fc546d2bf8e51a4d584bcaa6944e4885cbe22de58d`입니다. 원본 시험지의 3점 표시와 사본의 배점이 모두 일치했습니다.
