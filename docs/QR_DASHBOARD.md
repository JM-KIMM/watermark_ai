# 실제 URL QR과 접속 대시보드

`python webapp.py`로 생성기와 QR 수집기를 함께 시작합니다. 생성기는 내 컴퓨터의 `http://127.0.0.1:8766`, 대시보드는 같은 주소의 `/dashboard`입니다. 관리 화면은 루프백에만 열리고 관리 API에는 실행마다 바뀌는 토큰이 필요합니다.

PDF 선택 전에 발급 대상 또는 관리 번호를 입력할 수 있습니다. 문제마다 서로 다른 URL을 발급하고 발급 대상·시험지·쪽·문제 번호를 연결합니다. 같은 PDF를 여러 사람에게 배포하면 발급 대상을 구분할 수 없으므로 개인별 연결이 필요하면 각각 발급하세요.

QR 수집기는 기본적으로 현재 LAN 주소의 8765 포트에 열립니다. 같은 Wi-Fi의 기기에서 대시보드에 표시되는 주소의 `/health`를 열어 `ready: true`인지 확인하세요. 다른 기기에서 막히면 관리자 PowerShell에서 `tools/Enable-QR-LAN.ps1`을 실행할 수 있습니다. 이 규칙은 Private 네트워크의 같은 서브넷에서 오는 TCP 8765만 허용합니다.

LAN 주소는 같은 네트워크에서만 접근할 수 있습니다. 공유기 DHCP 예약 등으로 서버 주소를 고정하세요. 주소나 포트가 바뀌면 이미 인쇄한 QR은 자동으로 바뀌지 않습니다. 인터넷의 상용 AI 서비스가 이 사설 주소에 접속할 수는 없습니다. 인터넷 수집에는 별도의 공개 서버 주소와 배포가 필요합니다.

## 기록

대시보드는 1초마다 갱신하고 다음 항목을 표시합니다.

- 관측 IP, 발급 대상, 시험지, 쪽, 문제 번호, 한국 시각, 요청 방식, 상태
- 전체 접속 수, 처음 관측한 IP 수, 발급 시험지 수
- 전체 접속 CSV와 최초 IP CSV 내려받기
- 수집기 시작·중지, 발급 시험지 링크 중지·재개

기록 위치는 `data/qr_archive/`입니다.

| 파일 | 내용 |
|---|---|
| `archive.sqlite3` | 발급 링크와 접속의 기준 데이터. WAL 방식으로 저장 |
| `events.csv` | 모든 등록 링크 접속. GET와 HEAD, 중지된 링크의 410 응답도 기록 |
| `visitors.csv` | 정규화한 IP별 최초 접속 시각 |

CSV는 UTF-8 BOM으로 저장합니다. CSV 셀 수식 실행을 막기 위해 위험한 문자열에는 접두 문자가 붙을 수 있습니다. 앱 재시작 시 SQLite에서 CSV를 다시 작성하여 중단된 CSV 쓰기를 복구합니다. 백업은 앱을 종료한 뒤 폴더 전체를 복사하세요. 이 저장소는 위변조 방지 또는 법적 증거 보관 시스템으로 검증한 것이 아닙니다.

새 발급 링크와 접속 기록은 직접 중지하거나 삭제하기 전까지 로컬 보관합니다. 기존의 만료·개수 제한 CSV 기능과 별도로 동작하므로 `outputs/web`의 7일 정리는 이 기록을 삭제하지 않습니다. 살아 있는 과거 CSV 접속 기록은 앱 시작 시 중복 없이 가져옵니다. 이미 삭제된 과거 기록은 복원할 수 없습니다.

## 해석 한계

IP는 개인 신원이 아닙니다. 같은 공유기·VPN·AI 서비스의 서버 IP일 수 있으며, 링크 공유나 자동 미리보기도 접속을 만들 수 있습니다. 발급 대상은 관리자가 입력한 연결 정보입니다. **접속만으로 해당 사람이 부정행위를 했다고 확정할 수 없습니다.** 현장 감독 및 별도의 확인과 함께 검토하세요. IP·발급 대상이 포함된 기록은 GitHub에 올리지 마세요.

현재 모델 평가 클라이언트에는 URL 접속 도구가 없습니다. QR이 보였다고 모델이 실제 링크를 방문하는 것은 아닙니다. 모델 정답률, QR 해독 여부, 실제 HTTP 방문 기록을 각각 구분합니다.
