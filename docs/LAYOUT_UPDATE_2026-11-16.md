# 생성 화면과 PDF 배치 변경

> 이 문서는 바깥 여백 QR을 사용했던 v2의 작업 기록입니다. 현재 문제 끝 QR과 이미지 캡처 평가 결과는 [최신 캡처 평가](CAPTURE_RESULTS_2026-11-16.md)를 참조하세요.

- PDF 선택 즉시 기본 설정으로 생성합니다. 옵션 패널과 가상 미리보기를 없애고, 실제 첫 페이지 미리보기는 완료 후 펼칠 수 있게 했습니다.
- 웹 기본은 검정 글자·90% 불투명도·6pt·맑은 고딕이며 무작위 크기 변동을 없앴습니다.
- 문제별 QR을 각 단의 바깥 여백에 고정하고 문제 번호 높이에 정렬했습니다. 아래에 문제 번호와 접속 안내를 붙입니다. 본문 크기는 유지하고 사방 56pt를 추가합니다. 충돌 시 이동 대신 생략하고 기록합니다.
- 지문 내용은 보존하고 박스 테두리만 검은 워터마크 문구로 교체합니다. 줄마다 분리된 선, 제목이 끼어 있는 윗선, 본문 안의 작은 단어 강조 상자를 처리합니다. 표·도형·이미지·안전 간격이 부족한 박스는 보존합니다. 벡터 구조를 이용한 보수적인 탐지이므로 모든 지문 박스를 보장하지 않습니다.
- 수학 전용 수식, 기존 평가·QR 기록 API는 유지합니다. 간단 웹 화면은 IP를 수집하지 않습니다.

검증: `python -m unittest discover -s tests -t . -v`의 28개 테스트 통과. 보유 객관식 시험지 PDF 7종·221쪽의 시험 출력에서 QR이 원본 본문을 침범하지 않고 번호 높이에 정렬됨을 확인했습니다. 최종 국어 2쪽 출력은 교체한 테두리 영역을 제외한 본문 렌더링의 원본 대비 픽셀 차이가 0이었습니다. 브라우저에서 파일 선택에 따른 자동 생성·결과 링크와 데스크톱/390px 화면을 확인했습니다. 소스 전용 ZIP 생성도 확인했습니다.

이 검증은 배치와 내용 보존 검사입니다. **이번 디자인 변경 후 로컬 모델 점수는 재측정하지 않았습니다.** 기존 README와 평가 문서의 성능 수치는 이전 버전의 결과입니다. 시험지 원본과 생성 PDF는 GitHub에 포함하지 않습니다.
