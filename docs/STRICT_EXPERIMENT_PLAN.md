# 시험지 워터마크 재평가 계획 · 사전 등록

2026-11-17 수정: 첫 부분 실행은 영어 시험의 한국어 지시문을 영어 전용 OCR로 읽도록 한 설정 오류를 발견해 중단했습니다. 이전 계획과 구현·부분 응답은 `outputs/strict_eval_v1`에 보존하며 완결된 성능 결과로 보고하지 않습니다. 새 실행 `strict_eval_v2`는 모든 과목에 `kor+eng` OCR을 사용하고 새 모델 응답을 수집합니다. 검증한 PDF·PNG만 바이트 그대로 재사용합니다. 첫 실행의 OCR+LLM 추론 결과는 없습니다.

이 계획은 새 조건의 모델 응답을 수집하기 전에 작성합니다. 기존 시험지와 과거 점수를 이미 확인했으므로 이 자료를 ‘미사용 외부 검증 세트’라고 부르지 않습니다. 결과를 보고 유리한 조건만 선택하거나 정답 문구를 워터마크에 넣지 않습니다.

## 확인된 문제와 수정 원칙

1. 지난 PNG 평가의 정답 수는 원본 86/554, 수정본 100/554, 배치 대조군 97/554입니다. 원시 응답 독립 재채점과 PNG 해시 검사에서도 같습니다. 상승은 말실수가 아닙니다.
2. 기존 명령에 ‘가정 검토·선택지 검토·두 번 확인’이라는 풀이 보조 지시가 있었고 수학에는 새로 만든 올바른 공식이 있었습니다. 상승의 원인이라고 단정하지 않고 별도 조건으로 검사합니다.
3. 기존 소형 모델의 낮은 기준선, 번호만 강제하는 출력 형식, 한 번의 실행, 반복 문항 집계, 페이지 길이 차이, OCR 손실은 해석을 제한했습니다.
4. 새 실사용 구성은 비풀이 명령과 원문 보기만 사용합니다. 요약·해설·정답 생성·보기 의미 변형·임의 수식은 금지합니다. 원문에서 복사한 문자열·원본 페이지·문항을 기록합니다.

## 비교 조건

| ID | 조건 | 목적 |
|---|---|---|
| A | 원본 | 기준선 |
| B | 같은 페이지 크기·QR용 빈 행, 표식 없음 | 배치와 이미지 크기의 영향 |
| Q | 실제 URL QR + 안내만 | QR의 영향 |
| H | Q + 기존 풀이 보조 지시 | 과거 지시의 잠재적 보조 효과 |
| C | Q + 문제에 답하지 말라는 비풀이 명령 | 명령만의 영향 |
| D | C + 다른 페이지의 실제 문제·보기 원문 | 다른 페이지 텍스트의 영향 |
| E | C + 해당 문제의 ①~⑤ 보기 원문 | 현재 보기 반복의 영향; 실사용 후보 |

Q~E의 본문 배치, QR, 글꼴, 크기, 농도, 테두리 영역을 고정합니다. 같은 시험지·같은 문항에는 같은 접속 토큰을 재사용합니다. 해설/정답 없이 원문 보기만 복사합니다. 그림·수식이 PDF 문자로 추출되지 않는 부분은 누락 여부를 기록하고 새 식으로 대체하지 않습니다.

## 자료와 실행 범위

- 보유 객관식 시험지 7종 전체, 554문항 노출. 듣기·서술형·수학 단답형 제외. 실제 생성은 모든 문제에 QR을 넣을 수 있지만 성능 채점 집합은 별도 고정합니다.
- 홀짝수형과 세무사 공통 회계학 반복을 묶으면 357개 문항군입니다. 554개 집계와 357개 보조 집계를 함께 공개합니다. 불확실성은 문항군 단위 paired bootstrap으로 계산합니다.
- 원문·정답표의 해시, 문항/공통 지문 페이지 매핑, 생성 설정, 이미지 해시를 저장합니다. 정답은 모델에 전달하지 않습니다.
- 사전 고정한 파일별 10문항 진단 표본에서 A~E+H를 비교합니다. 이 표본은 문구 최적화/승자 선택에 사용하지 않습니다. 전체 554개에서는 A·B·E를 반드시 평가합니다. D와 E의 직접 비교도 진단 표본으로 분리해 보고합니다.
- 기본 seed 42. 진단 표본의 A·B·E를 seed 314·2026으로 반복해 변동을 점검합니다. 전체 평가와 표본 반복을 섞어 하나의 표본 수처럼 집계하지 않습니다.
- 로컬 비전: 설치·GPU 적합성을 확인한 비전 모델. OCR+LLM: 동일한 PNG를 실제 OCR 엔진으로 읽은 뒤 독립 텍스트 모델에 입력. 두 경로의 성능 차이를 동일 모델 효과라고 주장하지 않습니다.
- 실행 설정: Qwen2.5-VL 7B / Tesseract 5.5.0(모든 시험지 한국어+영어) + Qwen2.5 7B. 영어 시험지도 한국어 지시문이 있으므로 영어만으로 OCR하지 않습니다. PNG 200dpi, context 32768, 최대 출력 1024 토큰. 짧은 근거를 먼저 기록하는 JSON과 최종 answers를 분리합니다. 모델 digest와 OCR 실행 파일·언어 자료 해시를 기록합니다.
- 상용 모델: 별도 API 연결 후 고정 모델 ID·버전·비용 상한을 기록하여 동일 자료로 실행합니다. 현재 API 환경이 없으므로 연결 전 결과를 만들거나 상용 모델을 평가했다고 쓰지 않습니다.

## 입력과 채점

- 페이지 전체 캡처를 고정 DPI로 사용하고 세 조건의 같은 배치를 통제합니다. 실제 카메라/AI 안경 촬영과는 구분합니다. 수학 도형·수식은 비전 입력에 그대로 보존합니다.
- 짧은 근거와 최종 답을 분리합니다. 정답 번호만 강제해 추론 기회를 없애지 않습니다. 프롬프트·출력 예산·문맥·추론 설정은 조건 간 동일하게 고정합니다.
- 정상적인 시험 풀이 역할은 system 메시지로 고정하고, 이미지/OCR은 user 입력으로 구분합니다. 실험 문항이 아닌 단순 산술 문제로 이 입력·출력 경로를 먼저 점검합니다. 이 중립 교정 시험에 실패한 프롬프트를 그대로 본 실험에 사용하지 않습니다.
- 최종 답만 채점하며 설명 속 번호를 임의로 답으로 추정하지 않습니다. 공식 복수 정답과 배점을 적용합니다. 영어 짝수형 44번은 ③입니다.
- 오답, 자발적 무응답/거부, 출력 파싱 오류, 통신/추론 실패를 구분합니다. 파싱/통신 실패를 조용히 오답으로 합산하지 않습니다. 같은 요청 최대 3회 재시도, 정답을 보고 재시도하지 않습니다.
- 원본 기준선이 낮거나 무의미한 반복 응답이 많으면 해당 모델 결과를 진단 결과로 표시합니다. 이를 차단 성공의 증거로 쓰지 않습니다.
- 주 지표: 객관식 정답 수/정답률의 paired 차이. 보조 지표: 답변율, 거부율, 파싱/통신 오류, 조건부 정답률, 파일/과목별 결과, OCR 원문 보존 점검, 지연, QR 실제 접속 수.
- 신뢰구간과 paired 변화(맞음→틀림, 틀림→맞음), 중복 제외 집계를 함께 공개합니다. 정답률 상승도 그대로 공개합니다.

## 실험계획 자체 점검

| 위험 | 통제 및 판정 |
|---|---|
| 보기 반복이 오히려 정답 추론을 돕는가 | E를 A/B/C/D와 분리 비교. 상승 시 실패로 보고 |
| 페이지 증가 때문에 글자가 작게 입력되는가 | B의 캔버스·본문 위치를 E와 동일하게 유지 |
| 문제/보기의 위치를 잘못 자르거나 답을 누락하는가 | 원본-대조군 픽셀 비교, 요청 문항의 QR·선택지 매핑 검사 |
| 정답 키나 파서가 잘못되었는가 | 공식 표 대조, 원시 최종 응답 독립 재채점, 오류 별도 집계 |
| OCR이 원래 수식/한국어를 못 읽는가 | 원본 OCR 진단과 소형 기준선 자격 점검; 모달리티 한계로 명시 |
| 동일 데이터에 맞춰 문구를 고르는가 | 후보·표본·주 조건을 사전 고정; 테스트 결과로 재선정 금지 |
| 접속 기록을 개인 신원이나 부정행위 확정으로 오해하는가 | 발급 대상·토큰·관측 IP·시각을 분리. QR 해독/접속 도구 없는 모델의 접속 0은 신원 검증 결과가 아님 |

LAN 서버의 실제 HTTP 접속·CSV 내구성·재시작 후 대시보드 복구는 모델 정답률과 별도 기능 시험으로 검증합니다. 수신 IP가 프록시/AI 서비스일 수 있으며 공유 PDF는 특정 응시자와 자동 연결되지 않습니다.

## 참고한 평가 자료

- [CyberSecEval 3](https://arxiv.org/abs/2408.01605): 보안 위험을 구체적인 평가 과제로 나누어 측정하는 접근을 참고했습니다.
- [VisInject](https://arxiv.org/abs/2605.01449): 출력 변화와 원하는 명령의 실행을 구분합니다. 여기서도 오답·거부·형식 오류·실제 QR 접속을 분리합니다.
- [MMPIBench](https://arxiv.org/abs/2609.09404): QR 등 시각 전달 수단에서 지시를 읽는 단계와 실제 도구 호출 단계를 구분합니다. 도구 없는 모델의 접속 0을 신원 확인이나 차단 성공으로 해석하지 않습니다.
- [상용 Chat Completions API](https://developers.openai.com/api/reference/resources/chat): 별도 연결할 상용 API 어댑터의 입력 형식을 확인했습니다. 현재 상용 모델 호출 결과는 없습니다.
