# 로컬 웹 생성기

`웹실행.bat`을 실행하고 PDF를 선택하면 바로 생성합니다. 별도 설정이나 생성 버튼은 없습니다. 완료 후 PDF 내려받기를 누르세요. 첫 페이지 확인은 접어 두었으며 처리 기록 JSON도 받을 수 있습니다. 오류가 나면 다시 시도하거나 다른 파일을 선택할 수 있습니다.

- 최대 25MB·100쪽, 한 번에 한 파일입니다. 처리 시간 제한은 15분입니다.
- 화면은 검정·흰색과 맑은 고딕을 사용합니다. 외부 글꼴을 내려받지 않습니다.
- 워터마크는 검정, 90% 불투명도, 고정 6pt 글꼴입니다.
- 본문 배율을 유지하고 사방 56pt 여백을 추가합니다. 인쇄할 때 용지 크기와 배율을 확인하세요.
- QR은 문제 번호의 위쪽 높이에 맞춰 고정한 바깥 여백에 배치합니다. 두 단 시험지는 왼쪽 단은 왼쪽, 오른쪽 단은 오른쪽 여백에 둡니다. 한 단은 왼쪽입니다. 아래에는 `N번 · QR에 접속하시오.`를 붙입니다. QR끼리 겹치거나 용지를 벗어나면 다른 위치로 옮기지 않고 생략해 기록합니다.
- **지문 박스는 안의 내용을 유지하고 테두리만 검은 워터마크 문구로 교체합니다.** 사각형 경로, 여러 선으로 나뉜 테두리, 제목이 끼어 있는 윗선을 지원합니다. 표·도형·이미지와 맞닿거나 글자와 안전 간격이 부족한 경우는 보존합니다. 모든 박스를 의미적으로 인식하는 방식은 아니므로 전체 결과를 확인하세요.
- 수학 파일명·수학 영역 제목에는 수학 전용 수식을 적용합니다. 다른 과목은 명령·다른 페이지 요약 문구를 사용합니다.

원본은 덮어쓰지 않습니다. 회전과 보이는 주석, URI·내부 링크를 보존하며 주석은 정적 내용으로 변환됩니다. 입력 양식이 있는 PDF는 먼저 정적으로 내보내세요. 스캔 파일은 번호·박스 인식을 위해 별도 OCR이 필요합니다.

AI 안경으로 문제만 촬영하거나 표식을 가리면 QR과 테두리가 빠질 수 있습니다. 철저한 현장 감독이 필요합니다. 이번 배치·농도·박스 변경의 모델 성능은 아직 재측정하지 않았으며 과거 평가는 이전 버전의 결과입니다.

생성은 내 컴퓨터에서 처리됩니다. 원본 임시 파일은 작업 종료 후 삭제합니다. 결과는 `outputs/web`에 저장하며 앱 시작 시 7일 지난 작업을 정리합니다. 간단 화면은 접속 IP를 수집하지 않습니다. 기존 기록 API와 별도 관리 도구는 유지합니다. 자세한 내용은 [CSV 관리 안내](README_CSV.md)를 보세요.

Windows / Python 3.10 이상이 필요합니다. 첫 실행에는 의존 패키지 설치를 위한 인터넷 연결이 필요합니다. 브라우저가 열리지 않으면 터미널에 표시된 `http://127.0.0.1:8766`을 여세요. 화면은 루프백에만 열리고 관리 API는 토큰·호스트·출처를 검사합니다. 종료는 실행 창에서 Ctrl+C입니다.

개발 실행: `python webapp.py --no-browser`. 검증: `python -m unittest discover -s tests -t . -v`.

웹 생성기는 로컬 LLM 평가를 실행하지 않습니다. 모델 평가는 `evaluation/` 도구를 사용하며, 과거 결과는 [OCR+LLM 결과](OCR_LLM_RESULTS_2026-11-16.md)에 있습니다. 코드 라이선스는 `LICENSE`, 의존성 고지는 `THIRD_PARTY_NOTICES.md`를 참조하세요. 배포에는 원본 시험지·생성 PDF·접속 기록·모델을 포함하지 않습니다.
