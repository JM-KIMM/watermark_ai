# 로컬 웹 생성기

수학 파일명·수학 영역 제목은 수학 전용 수식 워터마크로 처리합니다. 다른 과목은 기존 문구를 유지합니다. QR 가까이에는 “QR에 접속하시오.” 안내를 붙이며, 본문과 겹치지 않는 공간이 없을 때는 안내만 생략하고 결과에 표시합니다. AI 안경·문제만 촬영·크롭으로 표식이 빠질 수 있으므로 현장 감독을 대체하지 않습니다.

2026-11-16 업데이트: 회전 PDF 표시 방향과 보이는 주석 내용을 보존하고 URI·문서 내부 링크를 복사합니다. 주석은 출력에서 정적인 본문으로 변환됩니다. 입력 양식이 있는 파일은 정적 PDF로 내보낸 뒤 사용하세요. 업로드 원본은 작업 종료 후 삭제하며, 결과 파일은 앱 시작 시 7일이 지난 작업 폴더에서 정리합니다. 맑은 고딕 기반 흑백 화면을 사용합니다. 로컬 모델 시험 성능 비교는 `docs/LOCAL_EVALUATION.md`를 참조하세요.

Windows에서 Python 3.10 이상을 설치한 뒤 `웹실행.bat`을 더블클릭하세요. 첫 실행에는 가상환경과 필수 패키지를 자동으로 설치하므로 인터넷 연결이 필요합니다. 이후 생성 작업은 내 컴퓨터에서 수행합니다. 브라우저가 열리지 않으면 터미널에 표시된 `http://127.0.0.1:8766`을 여세요.

1. PDF를 선택합니다. 한 번에 최대 25MB·100쪽입니다.
2. 강도를 선택합니다.
3. 생성 후 첫 페이지를 확인하고 PDF를 내려받습니다.

| 강도 | 동작 |
|---|---|
| 1 | 문제 주변 QR. 원래 페이지 크기 유지. |
| 2 | QR + 사방 테두리. 상단·우측은 문구 A, 하단·좌측은 문구 B를 각각 처음부터 반복. |
| 3 | 2단계 + 고립된 긴 구분선 후보를 QR 유래 무늬로 교체. |

3단계는 사각형·연결된 축·격자·본문에 가까운 선 등을 제외하는 보수적인 규칙을 사용합니다. 모든 도표를 의미적으로 판별하는 것은 아니므로 결과를 확인하세요. 변경 가능한 선이 없으면 0개로 표시합니다. 선 무늬 자체는 디코딩 가능한 QR이 아닙니다. 언어와 무관한 QR 무늬를 사용하며 아랍어 문자 변환은 포함하지 않습니다.

2·3단계는 원래 본문의 배율을 유지하기 위해 페이지 바깥에 테두리를 추가합니다. 출력 용지 크기가 달라집니다. 원본 PDF는 덮어쓰지 않습니다.

`세부 설정`에서 글자 크기·농도·크기/가로 비율 변동·QR 크기/위치를 바꿀 수 있습니다. QR 접속 기록을 켜면 한국 시각으로 접근 시작·종료 시간을 지정합니다. 시작 전에는 403, 종료 후에는 410 응답을 보내며 접속 기록을 추가하지 않습니다.

IP 수집은 기본으로 꺼져 있습니다. 켠 경우 `기록 시작`으로 별도 QR 접수 서버를 시작해야 합니다. 기본 주소 `127.0.0.1:8765`는 같은 PC에서만 작동합니다. 외부 AI 접속에는 외부에서 도달할 수 있는 주소와 서버가 필요합니다. 공개 호스팅·TLS는 자동 설정하지 않습니다. 접속 IP와 시각은 `data/qr_csv`에 저장하며 `CSV 받기`로 내보낼 수 있습니다. 수신 IP가 AI 사업자·VPN·프록시의 IP일 수 있습니다.

앱 화면은 `127.0.0.1`에만 열립니다. 웹 관리 요청은 실행마다 달라지는 토큰과 호스트/출처 검사를 사용합니다. QR 접수 서버에는 PDF 생성·관리 API를 노출하지 않습니다. 전체 앱을 종료하려면 실행 창을 닫거나 Ctrl+C를 누르세요.

PDF 처리는 한 번에 하나씩 별도 프로세스에서 수행하고 15분 후 중단합니다. 처리 중 다른 생성 요청은 받지 않습니다. 파일·결과는 `outputs/web`에 저장됩니다. 생성 파일과 접속 기록은 배포 ZIP에 포함하지 않습니다.

현재 요약은 로컬 대표 문장 추출입니다. 로컬 LLM과 `skt/A.X-4.0-Light`는 연결하지 않았습니다. 웹 생성기는 시험지 풀이·답지 다운로드·모델 성능평가를 실행하지 않으며, 별도 평가 도구로 수행한 로컬 모델 비교는 `docs/CORPUS_RESULTS_2026-11-16.md`에 있습니다. 읽을 텍스트가 없는 스캔 PDF에는 별도 OCR이 필요합니다. 브라우저의 보관 기록은 세션 단위이며 이전 결과 파일은 `outputs/web`에서 찾을 수 있습니다.

개발 실행: `python webapp.py --no-browser`. 기능 검증: `python -m unittest discover -s tests -t . -v`.
