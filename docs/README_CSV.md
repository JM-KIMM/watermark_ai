# 기존 CSV 관리 도구와 과거 워터마크 비교

현재 간단 웹 생성기는 [QR 대시보드](QR_DASHBOARD.md)의 영구 보관 방식을 기본으로 사용합니다. 아래는 기존 도구의 만료·개수 제한 CSV 방식이며 새 대시보드의 보관 정책과 구분해야 합니다.

브라우저 사용자는 [프로젝트 소개](../README.md)와 [로컬 웹 사용법](WEB_README.md)을 먼저 확인하세요. 아래 `outputs/` 샘플 경로와 과거 측정값은 로컬 개발 기록이며, 실제 시험지와 생성 결과는 공개 저장소·배포 ZIP에 포함하지 않습니다.

## 실행

```powershell
python -m pip install -r requirements.txt
python tools/app.py
```

`tools/실행.bat`은 생성 창, `tools/DB관리.bat`은 현재 CSV 관리 창을 엽니다. 화면의 QR 접속 기록 여부를 끄면 서버 없이 PDF 생성·로컬 파일 관리만 사용합니다. 기본값은 본문 모양 재사용, 크기 ±25%, 가로 비율 고정, 문제별 QR, CSV 연결입니다. ±25%는 검증된 최적값이 아닙니다.

## 파일 저장

관리는 `data/qr_csv/`의 UTF-8 BOM CSV 5개를 사용합니다.

| 파일 | 내용 |
|---|---|
| campaigns.csv | 발급·유효 기간·보관 기간·기록 상한 |
| tokens.csv | QR 토큰·페이지·문제 번호 |
| scans.csv | 접속 시각(Unix 초)·관측 IP·토큰 |
| cases.csv | 수동 작성 사건·검토 상태·접속 연결 |
| counters.csv | 삭제 후에도 중복되지 않는 기록 번호 |

Excel에서 관리할 수 있도록 CSV 내보내기를 제공합니다. 내보낸 접속 시각은 한국 시각 ISO 형식입니다. 실행 중 원본 CSV를 Excel로 편집하면 파일 잠금 때문에 접수가 503으로 실패할 수 있습니다. 서버를 중지한 뒤 편집하거나 내보낸 복사본을 확인하세요. 열 이름·숫자 형식을 바꾸면 파일을 읽을 수 없습니다.

필드 인용과 수식 시작 문자 이스케이프를 사용합니다. CSV라는 이유만으로 모든 위험이 사라지는 것은 아니며, Excel에서 재저장하면 보호 문자가 바뀔 수도 있습니다. 파일은 텍스트 형식으로 가져오고 외부 입력을 수식으로 실행하지 마세요.

여러 스레드·프로세스의 파일 접근을 잠금으로 조정하고, 파일별 임시 저장 후 교체합니다. 여러 CSV 파일을 동시에 교체하는 데이터베이스 수준의 단일 트랜잭션은 아닙니다. 전원 차단 등으로 중간 상태가 생기면 다음 정리에서 고아 토큰·접속을 제외하고 사건의 끊어진 연결을 비웁니다. 대규모 트래픽용 저장소로 성능을 검증하지 않았습니다.

이전 SQLite를 옮기는 명령은 다음과 같습니다. 원본은 읽기 전용으로 열고 삭제하지 않습니다. 대상 CSV 폴더가 비어 있어야 합니다.

```powershell
python tools/migrate_legacy.py data/qr_access.sqlite3 data/qr_csv
```

## QR와 서버

CSV는 저장 형식이며 IP 자동 수집에는 접속을 받는 서버가 필요합니다. 외부 DB 서버와 연결하지 않습니다. 서버가 꺼져 있으면 신규 IP는 기록되지 않고 기존 파일은 계속 조회할 수 있습니다.

```powershell
python tracking_db.py --db data/qr_csv --host 127.0.0.1 --port 8765 --requests-per-minute 120 --workers 8
```

관리 화면에서도 서버 시작·중지가 가능합니다. `127.0.0.1`은 같은 PC에서만 작동합니다. 외부 AI 서비스가 방문하게 하려면 공개 접근 가능한 주소와 실행 중인 서버가 필요합니다. 이 프로그램은 호스팅·TLS·방화벽을 자동 설정하지 않습니다. QR을 해독만 하고 접속하지 않으면 IP 기록이 생기지 않습니다.

접속 IP는 AI 사업자·VPN·프록시의 주소일 수 있습니다. IP 변경만으로 같은 사람이라고 판정하거나 원래 주소를 알아낼 수 없습니다. 임의의 전달 헤더는 저장 IP로 사용하지 않습니다.

요청 제한 기본값은 토큰당 분당 20회, IP당 30회, 전체 120회입니다. VPN 회전에도 토큰별·전체 상한은 유지됩니다. 동시 처리 8개, 대기 큐 16개, 소켓 시간 제한 5초를 적용합니다. 한도 초과는 429, 작업 슬롯 부족이나 저장 장애는 503입니다. 파일 문제가 해소되면 다음 요청부터 다시 처리합니다. 네트워크 전체가 포화되는 공격까지 방어하는 서비스는 아닙니다.

과부하 시에는 서버를 중지하고 로컬 CSV로 기존 기록을 확인할 수 있습니다. 서버가 중지되거나 실패한 기간의 IP를 나중에 소급 수집하지는 못합니다. 무한 QR 연쇄·자동 이동·외부 시스템 역접속은 포함하지 않습니다. 일반 스캔에는 작은 고정 JSON 응답만 반환합니다.

링크·접속 보관은 기본 7일이고, 1~90일 범위로 설정합니다. 캠페인별 1000건(최대 10000건), 전체 접속 10000건·사건 1000건·캠페인 100개·QR 20000개 상한이 있습니다. 정리는 접속·조회·생성 시와 서버 동작 중 약 30초마다 수행합니다. 모두 종료한 상태에서는 다음 실행까지 파일의 물리적 정리가 진행되지 않습니다.

## PDF 옵션

```powershell
python watermark.py "세법학1부.pdf" -o outputs/custom_csv.pdf --question-style both --qr-size 40 --size-jitter 0.25 --width-jitter 0.1 --qr-placement local-random --font-mode source --prompts prompts_ko.json --db data/qr_csv --base-url http://127.0.0.1:8765
```

모든 페이지의 테두리 문구에는 QR 해독·주소 접속 지시가 들어갑니다. 이 지시가 실제 모델에서 실행된다고 보장하지는 않습니다.

`fixed`와 `local-random` 모두 문제마다 QR 한 개를 배치합니다. 후자는 문제 제목 주변 후보의 순서만 섞습니다. 원본 텍스트·이미지·도형과 겹치거나 페이지 밖이면 제외하고, 빈 공간이 없으면 생략합니다. 계산 공간에 대한 실제 수험자 평가를 수행한 것은 아닙니다.

문제 번호는 원래 번호 글자의 실루엣에 QR 유래 무늬를 넣습니다. **번호 무늬 자체는 디코딩 가능한 QR이 아닙니다.** 실제 URL은 별도 정상 QR에 담습니다. 원래 PDF 텍스트 계층은 남습니다.

`--size-jitter`는 글자 크기, `--width-jitter`는 가로 비율의 변동입니다. 시드가 같으면 같은 조건의 배치를 재현합니다. `source` 글꼴 모드는 원본 글자 모양을 재사용하고 없는 문자는 대체 글꼴로 표시합니다. 원래 TTF가 있다면 `--font-mode file --font ...`로 직접 지정할 수 있습니다.

본문을 원래 크기로 유지하도록 바깥에 테두리를 추가하므로 출력 용지 크기는 커집니다. 현재 자동 OCR은 없고, 텍스트가 없는 PDF의 요약은 별도 JSON으로 제공해야 합니다. 요약은 생성형 요약이 아닌 로컬 대표 문장 추출입니다.

## 샘플·검증

- `outputs/tax_csv_fixed.pdf`: 문제별 고정 위치, 크기 ±25%, 가로 비율 ±10%, CSV 연결.
- `outputs/tax_csv_random.pdf`: 동일 조건에서 문제 주변 위치를 무작위화.
- `experiment_plan.csv`: 72개 조합의 측정 계획. OCR·정답률·지연 시간 결과는 아직 비어 있습니다.
- `RESEARCH.md`: 논문의 관측 결과와 프로젝트의 가설 구분.

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -t . -v
python tools/verify.py
python tools/verify_question_marks.py
```

CSV 기록·동시 쓰기·보관 기한·수식 이스케이프·읽기 전용 이관·요청 제한·장애 후 복구, 글자 변동 범위·시드 재현·QR 겹침을 검증합니다. QR 복원률은 실제 PDF에서 QR만 잘라낸 디지털 이미지 기준이며 휴대전화 촬영이나 AI 방해 성능을 뜻하지 않습니다. 기존 샘플과 새 샘플의 측정은 `outputs/qr_metrics.json`에 있습니다.

현재 측정: 기존·추가 샘플 총 60쪽의 의도하지 않은 본문 변경이 없는지 검증을 통과했고, 배치된 QR 100개가 150·300dpi에서 각각 100/100 복원됐습니다. 위치 비교용 두 PDF는 같은 문구·글자 변동·QR URL과 무늬를 사용하고 위치만 바꿨습니다. 두 샘플은 각각 4/4 복원으로 이 작은 표본에서는 우열이 없었습니다. QR 해독 → 실제 로컬 URL 요청 → CSV IP 저장도 확인했습니다. OCR 정답률·AI 지연 시간·수험자 풀이 시간은 아직 측정하지 않았습니다.
